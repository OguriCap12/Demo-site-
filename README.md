# Ember & Olive

A polished single-page demo website for **Ember & Olive**, a fictional premium Mediterranean restaurant concept based in Defence Colony, New Delhi.

## Features

- Editorial, high-end hospitality design direction
- Responsive single-page experience for mobile, tablet and desktop
- Sticky navigation with elegant mobile menu
- Cinematic hero section and art-directed restaurant storytelling
- Signature dishes showcase with fictional pricing
- Interactive category-based menu
- Editorial gallery with accessible lightbox
- Reservation modal with validation and demo-only messaging
- Stylized location section with fictional address and hours
- Accessibility-conscious interactions, focus states and reduced-motion support

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Demo Notes

- This project is a **fictional portfolio/demo website**.
- The restaurant, testimonials, chef identity and reservation flow are presented as concept content.
- **Reservations do not actually process** and no booking or payment system is connected.
